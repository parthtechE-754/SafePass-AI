Key Implementation Points
Backend
FastAPI — REST API with async endpoints for risk prediction & hazard classification
Jinja2 — server-side HTML rendering for the interactive map interface
2-tier fallback — trained ML model → analytical engine, ensuring zero downtime
Machine Learning
Model 1 — CRI Engine: GradientBoostingRegressor · 12,000 samples · R² = 96.8%
Model 2 — NLP Classifier: TF-IDF + Logistic Regression · 3,500 reports · 100% accuracy
SHAP TreeExplainer — feature attribution per prediction, human-readable driver advice
Inference latency — <4ms (CRI) and <2ms (NLP), fully runs on CPU
Data Sources
MoRTH blackspot data — 500+ high-fatality highway corridors across 4 states
Open-Meteo API — live weather: rain, visibility, wind, temperature per location
Supabase — real-time citizen hazard reports stored and queried instantly
Frontend & Deployment
Google Maps JavaScript API — route overlay, risk heatmap, danger zone markers
Cloudflare Tunnel — live public deployment, no cloud VM or domain required
