Algorithm & Platform Development:

Corridor Risk Index (CRI) Algorithm:

SafePass AI implements a 5-factor multi-parametric risk engine evaluating highway safety per 200m road segment. The engine dynamically calculates real-time risk before travel:

CRI = 0.35(A) + 0.25(W) + 0.20(G) + 0.12(T) + 0.08(I) 0.0 – 10.0 INDEX

• Accident History (A - 35%): Distance-decay spatial proximity to MoRTH/NHAI blackspots and historical annual fatalities.
• Weather Hazard (W - 25%): Real-time Open-Meteo satellite weather (rainfall aquaplaning, fog visibility, wind gusts).
• Road Geometry (G - 20%): Mountainous ghat hairpin bends, steep descent gradients, speed limits, and lane widths.
• Temporal Diurnal (T - 12%): MoRTH peak fatigue night-driving curve (18:00–04:00) & monsoon spikes.
• Infrastructure (I - 8%): Median separation barriers, road shoulder availability, and solar illumination.

Platform & Geospatial Architecture:

Frontend: Google Maps-style progressive navigation built with MapLibre GL JS (token-free vector & Esri World Street tiles), Web Speech API for real-time spoken voice driver advisories, and Geolocation radar GPS tracking.
Backend: High-throughput Python 3.13 (FastAPI ASGI) engine integrated with OSRM routing and Haversine spatial geodesic matrices for multi-route corridor optimization.

Resilience & Emergency Telemetry:

Supabase Cloud Database with Row Level Security (RLS) stores trip history and crowdsourced hazard reports. Features zero-cold-start local resilient fallback for offline operations and instant 1-click SOS telemetry dispatching live GPS coordinates to 112 / 1033 NHAI emergency patrols.
